# Оперативный дашборд: активы и логистика

Прототип по [PRD.md](PRD.md) (версия 0.4). Одна страница с ежедневной картиной по активам: ключевые показатели, 9 разделов, детализация станций Достык и Алтынколь, отраслевой дайджест.

## Как открыть

**Онлайн:** https://ktz35.github.io/Dashboard/ (GitHub Pages, обновляется после каждого push в `main`).

**Вариант 1. Двойной клик.** Откройте `index.html` в браузере (Chrome, Edge, Firefox). Сервер и установка не нужны.

**Вариант 2. Локальный сервер** (удобно, чтобы делиться ссылкой в локальной сети или открыть во встроенном браузере):

```bash
powershell -ExecutionPolicy Bypass -File tools\serve.ps1
```

Затем откройте http://localhost:8080/.

## Структура

```
index.html            страница
css/styles.css        стили (светлая и тёмная тема, адаптивность от ~400 px)
js/core.js            CSV, расчёты из раздела 5 PRD, пороги, форматирование ru-RU
js/charts.js          графики на SVG (подсказки, подписи, описание для экранного диктора)
js/app.js             шапка, ключевые показатели, вкладки, страница станции, блок «О данных»
data/*.js             наборы данных в формате CSV (по шаблонам из раздела 5 PRD)
tools/serve.ps1       локальный веб-сервер на PowerShell
tools/generate-demo-data.ps1  генератор демо-данных: перевалка, терминалы станций, вагоны
```

## Данные

Каждый набор из раздела 5 PRD лежит в своём файле `data/<набор>.js`: внутри обычный CSV между обратными кавычками, плюс источник, статус и время обновления.

Заменить данные можно двумя способами:

1. **В интерфейсе.** Блок «О данных и показателях» → «Заменить файлом» у нужного набора. Колонки должны совпадать с шаблоном (разделитель — запятая или точка с запятой, кодировка UTF-8). Загруженный файл хранится в этом браузере; «Вернуть встроенные» сбрасывает замену.
2. **В файле.** Вставьте свой CSV в `data/<набор>.js` вместо текущего.

Любой набор скачивается в CSV кнопкой «CSV ↓» под таблицей или в блоке «О данных».

Правила:
- Перевалка станции всегда считается как сумма её терминалов из `station_terminals`, поэтому в разделах «Объёмы», «Терминалы» и на странице станции цифры совпадают.
- Порядок объектов задаётся полем `order` в `sites`.
- Пороги (90% плана, простой от 3 суток, волна от 2,5 м, порывы от 20 м/с) — в `THRESHOLDS` в начале `js/core.js`.

## Что демо, а что нет

- Все операционные цифры выдуманы. Названия терминалов Достыка настоящие, объёмы по ним — нет.
- Терминалы Алтынколя, компании группы, маршруты, суда и рейсы — условные (PRD, раздел 9).
- **Дайджест — реальные публикации** за июль–ноябрь 2026 г. со ссылками на статьи, пересказ своими словами. Обновляется вручную в `data/digest.js`.
